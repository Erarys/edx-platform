Добавить новые вопросы

Одна строка Excel — один вопрос. Столбцы: question, variant1–variant4, correct_answer, type. При необходимости добавьте варианты до variant10.

single — одиночный выбор, multi — несколько ответов, dropdown — выпадающий список. В correct_answer укажите номера: 2 или 1,3.

Для single с несколькими правильными номерами засчитывается любой один из них; для multi нужно выбрать все указанные варианты.

text — текст без учёта регистра, text_case_sensitive — с учётом регистра, numeric — число. Для них варианты пустые, в correct_answer — сам ответ. Допустимые текстовые ответы разделяйте || ; числовой допуск пишите 4 ± 0.1 или 4 ± 5%.

Не объединяйте ячейки; сохраняйте файл как .xlsx. Загрузка создаёт новые компоненты. Поддерживается текст без изображений и скриптов. До 2000 вопросов и 5 МБ за одну загрузку. Невидимые символы и лишние пробелы по краям убираются при проверке; ошибки показаны по строкам.
