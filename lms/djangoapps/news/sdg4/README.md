# ЦУР 4: открытые учебные ресурсы

Публичный раздел `/sdg4/` реализован внутри приложения `news`. Он не создаёт
курсы Open edX и не требует регистрации или записи на курс.

## Страницы и наполнение

- `/sdg4/`: преамбула и все 17 факультетов, включая пока пустые.
- `/sdg4/<faculty>/`: преподаватели по алфавиту, с учётом русского и казахского алфавитов.
- `/sdg4/<faculty>/<surname-initials-id>/`: постоянная страница преподавателя.
  Три курса доступны по `?course=1`, `?course=2`, `?course=3`; навигация работает без JavaScript.
- `/sdg4/manage/`: список опубликованных страниц и черновиков для модератора.
- `/sdg4/manage/new/`: добавление преподавателя, `/sdg4/manage/<news_id>/`: редактирование.

Модератор должен быть активным staff-пользователем с разрешением `news.change_news`.
Для добавления также нужно `news.add_news`. Суперпользователь имеет оба разрешения.
Ссылка на управление видна модераторам на всех страницах раздела.

Форма содержит данные преподавателя, необязательные фото и ссылку на MOOC,
затем ровно три курса. Любой курс может быть лекционным или видео; комбинация
свободная. Обязательны темы, дисциплины и аннотации на kk/ru/en, язык материалов,
шифр образовательной программы, лицензия CC и хотя бы одно занятие в каждом курсе.
Аннотация ограничена 500 знаками для каждого языка. Порядок занятий совпадает
с порядком ввода. Кнопка добавления занятия работает на нативных Django formsets.
Для удаления занятия используется флажок в его форме.

Черновик сохраняется тем же способом, без флажка публикации. Публичный каталог
и страницы преподавателей не показывают черновики. Первый выход в публикацию
автоматически закрепляет дату размещения каждого курса.

После первого сохранения факультет и адрес нельзя изменить через форму.
К введённой фамилии и инициалам добавляется ID записи, поэтому однофамильцы
не конфликтуют. Исправление ФИО, переводов или материалов не меняет URL заявки.

## Данные и файлы

Новые таблицы и миграции не нужны. Используются существующие `news_news`,
пользователи и разрешения Django. Одна запись News хранит одну страницу
преподавателя; `content` содержит документ JSON версии 1 с профилем, тремя
курсами, материалами и статистикой. `title` содержит служебный неизменяемый
ключ `__sdg4__:<faculty>/<slug>`; существующее поле `image` хранит фото.

Служебные записи исключены из новостей и стандартного NewsAdmin. Префикс
зарезервирован в форме новостей; редактировать ресурсы следует через раздел
управления, а не вручную в JSON. Обычные новости сохраняют своё поведение.

Файлы сохраняются через настроенный Django `default_storage` в `sdg4/<news_id>/`.
Можно загрузить файл через форму либо указать уже существующий адрес файла
на сайте: `/media/...pdf`, `/asset-v1:.../...pdf` или HTTPS-ссылку. Сервер не
скачивает содержимое произвольных ссылок. Загруженные PDF отдаются публичным
FileResponse для просмотра и скачивания; для существующих URL выполняется
переадресация. При внешней ссылке режим скачивания зависит от сервера файла.
Для гарантированного ответа с `Content-Disposition: attachment` загружайте PDF
непосредственно через форму раздела.

Видео: MP4, WebM, OGV на университетском сервере либо YouTube. Для обычного
видео обязательны WebVTT-субтитры и длительность в секундах. Для YouTube
модератор подтверждает принадлежность университетскому каналу и наличие
субтитров; iframe строится из проверенного ID, HTML-код редактор не вводит.
Автоматическая проверка владельца YouTube-канала не выполняется.

Настройки при необходимости:

- `SDG4_MAX_UPLOAD_BYTES`: максимальный размер одного файла, по умолчанию 512 МБ.
- `SDG4_MEDIA_HOSTS`: дополнительные точные имена хостов университетского видеохранилища/CDN.
  Также разрешены домены КазНУ и хосты из `MEDIA_URL`/`LMS_ROOT_URL`.
- Фото: JPEG, PNG, WebP до 10 МБ.

Настройки reverse proxy должны допускать нужный размер запроса и загрузку
нескольких файлов. Веб-сервер/CDN должен публично отдавать `MEDIA_URL`, поддерживать
Range-запросы для видео и `text/vtt` для субтитров. При отдельном домене медиа
нужен CORS для `<video crossorigin="anonymous">` и дорожек субтитров.
Медиа этого раздела предназначены для открытого доступа; черновик скрывает
страницу, но не превращает стандартное публичное MEDIA-хранилище в приватное.

При неудачном сохранении вновь созданные файлы удаляются. Ранее опубликованные
файлы автоматически не удаляются при замене, чтобы не ломать уже выданные ссылки.

## Статистика

Открытие страницы с выбранным курсом увеличивает его `views`. Кнопка скачивания
PDF увеличивает `downloads`. Это число запросов, не уникальных людей и не
подтверждённых полностью завершённых скачиваний. Просмотр PDF отдельно от кнопки
скачивания не увеличивает downloads. Счётчики сохраняются при редактировании.
Изменения JSON сериализуются блокировкой `select_for_update` в транзакции;
редактор также проверяет версию по `updated_at`, чтобы обнаружить чужую правку.

## Локализация и выкладка

Поддерживаются kk (кнопка KZ), ru и en. Язык меняет интерфейс, преамбулу,
названия факультетов и переведённые данные преподавателя/курсов. Название
занятия и сами файлы остаются на указанном языке материалов.
Переключатель использует языковую cookie и существующий UserPreference Open edX
для вошедших пользователей. Общие переводы находятся только во втором репозитории:

`openedx-translations/translations/edx-platform/conf/locale/{en,kk,ru}/LC_MESSAGES/django.po`

После доставки обоих коммитов штатный процесс Atlas должен забрать эти каталоги,
а сборка Open edX — скомпилировать сообщения и собрать статические файлы.
Для локального интерфейса используются `lms/static/sdg4/showcase.css` и
`lms/static/js/sdg4-editor.js`. После обычной сборки/перезапуска LMS открыть
`/sdg4/` и `/sdg4/manage/`. Страницы появятся сразу; учебные материалы добавляет модератор.

`lms/templates/course.html` является карточкой одного MOOC, поэтому вход в раздел
добавлен в общий header для гостей/авторизованных пользователей и в настоящий
шаблон главной страницы `lms/templates/index.html`.

Названия факультетов сверены с меню https://www.farabi.university/?lang=en
и https://farabi.university/?lang=kz. Казахские формулировки преамбулы взяты из ТЗ;
до публичной выкладки их следует вычитать носителю-редактору, как указано в ТЗ.
Количественные условия конкурса сверх обязательных трёх курсов не придуманы:
ТЗ отсылает за ними к отдельным методическим рекомендациям.

## Проверки

Из корня `edx-platform` в окружении с Django 4.2, Mako и Pillow:

```powershell
.\.venv\Scripts\python.exe lms/djangoapps/news/sdg4/tests/run.py
```

Изолированный runner пропускает только запуск LMS Celery и заменяет общий
шаблон оболочки. Используются реальные Django ORM, миграции существующей News,
формы, загрузки, middleware, URL и Mako-шаблоны нового раздела. Проверяются
публикация, три курса, гостевой доступ, файлы, субтитры, права, CSRF, постоянные URL,
локализация, счётчики, порядок занятий и конфликт редактирования.
Это дополняет, но не заменяет smoke-проверку полной сборки LMS в Tutor.
