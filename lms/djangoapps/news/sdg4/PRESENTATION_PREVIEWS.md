# Предпросмотр презентаций SDG 4

PDF показывается непосредственно в публикации и не требует дополнительного ПО.
Для PPT/PPTX LMS создаёт PDF-копию при первом открытии предпросмотра и сохраняет
её в `default_storage` по пути `sdg4/<news_id>/previews/<material_id>.pdf`.
Исходная презентация не изменяется и остаётся доступной для скачивания.

В образе LMS должен быть установлен LibreOffice с компонентом Impress. Код ищет
исполняемые файлы `libreoffice` и `soffice`. При необходимости путь и поведение
можно настроить в Django settings:

```python
SDG4_PRESENTATION_PREVIEW_ENABLED = True
SDG4_PRESENTATION_CONVERTER = "/usr/bin/libreoffice"
SDG4_PRESENTATION_PREVIEW_TIMEOUT = 120
```

Конвертер запускается без shell, в headless-режиме, с отдельным временным
профилем и ограничением времени от 10 до 600 секунд. Если LibreOffice отсутствует
или не смог обработать файл, публикация остаётся доступной, а интерфейс предлагает
скачать оригинал. Для уже загруженных PPT/PPTX миграция данных не нужна: кэш
создаётся при первом просмотре. При удалении публикации её кэш также удаляется.
